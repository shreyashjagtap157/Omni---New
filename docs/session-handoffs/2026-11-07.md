### Implementation decisions and source changes

**Edition 1 parser authority**

- `Parser::from_source` now constructs `ParserProfile::Edition1`; the production driver and public compile/execute paths therefore reject unratified Vibe-first syntax by default.
- Pipeline `|>`, optional navigation `?.`, leading-dot projection shorthand, and standalone expression-placeholder `_` are only accepted by the explicit non-normative `ParserProfile::ExperimentalVibeSyntax`.
- The lexer’s standalone underscore remains usable as a wildcard in pattern position; the parser classifies it contextually and rejects expression-placeholder use in Edition 1.
- The pipeline operator has no Edition 1 binding power. Candidate-3 precedence is isolated in `experimental_binding_power`.
- Experimental driver execution remains test-only. Optional navigation remains unsupported by driver lowering; command-call syntax remains disabled.
- Candidate-2 newline termination and optional semicolons remain disabled/unimplemented.
- `spec/grammar/omni-edition1.ebnf`, the manifest digest, registry lifecycle states, and Candidate-2/3 ratification status were not modified.

**Ownership / borrow-state integrity**

- Reusing a live loan region for a different place or mutability returns `DuplicateLoanRegion`; re-observing the identical abstract loan is idempotent for dataflow fixed points.
- CFG ownership joins now return a typed error when predecessor states assign one region identity to different loan records. Identical loans merge once; the may-live loan set is retained conservatively.
- Verifier loan release propagates `UnknownLoan` instead of discarding the `end_loan` result; cleanup metadata is updated only after the underlying loan has been removed successfully.
- Active-child detection traverses the full reborrow-descendant graph. An ancestor loan is retained while any reachable grandchild/deeper reference remains live, even when intermediate reference locals are dead.
- Repeated observations of one stable reborrow region union possible immediate parent provenance rather than overwriting the prior path’s ancestry.
- Regression coverage includes conflicting region reuse, mutability rebinding, idempotent observations, conflicting/identical CFG predecessor loans, failed release invariants, transitive parent→child→grandchild retention, and parent-provenance union.

**Fallible memory allocation**

- `omni-runtime::Runtime::allocate` and the separate reference-machine `omni-machine::Memory::allocate` now reserve byte storage and initialization bitmaps with `try_reserve_exact`.
- A failed reservation returns an explicit allocation/memory error, publishes no allocation, and does not consume the next handle.
- The runtime’s signed-`i64` allocation API enforces the representable handle limit before publishing an allocation; the first unrepresentable handle is rejected rather than converted to the zero/failure sentinel.
- Regression coverage exercises oversized allocation failure, handle non-consumption, the largest representable signed runtime handle, and rejection beyond the ABI limit.
- The runtime remains an opaque-handle/process-local service; this work does not establish a fully exported native target ABI or target-specific aligned raw-pointer allocator.
